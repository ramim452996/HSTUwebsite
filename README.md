# FeastHub 🍔 - Ultra-Fast Gourmet Food Delivery Platform

**FeastHub** is a modern, high-performance, responsive food delivery web application crafted with pure vanilla HTML5, CSS3, and JavaScript. It delivers a fast, interactive online food ordering experience featuring custom dish builders, real-time live order tracking simulations, promo engine discounts, and campus delivery zones.

---

## 🌟 Key Features

- **🚀 Ultra-Fast Responsive UI**: Designed with glassmorphism, fluid micro-interactions, dark/light theme switching, and CSS grid/flexbox.
- **🔍 Smart Autocomplete Live Search**: Real-time dish and kitchen lookup with instant search previews and tag filtering.
- **🏷️ Multi-Facet Filtering & Sorting**: Filter by Cuisines, 4.5+ Rating, Under 20-Min Delivery, Halal Certified, Vegetarian, Student Specials, and Price ordering.
- **🛠️ Custom Dish Builder Modal**: Customize portion sizes (Regular, Large, Monster), spice levels (Mild, Medium, Flaming Hot), and delicious add-ons with automatic price calculation.
- **🛒 Dynamic Slide-Out Cart Drawer**:
  - Live quantity adjustment & item remove.
  - Coupon code engine (`FEAST50` for 50% discount, `HSTUFREEDEL` for free delivery, `SAVER20` for 20% discount).
  - Customizable driver tips ($1, $2, $3).
  - Itemized bill breakdown with instant tax & delivery calculations.
- **💳 Multi-Step Checkout Flow**:
  - Step 1: Customer details, address, and delivery notes.
  - Step 2: Payment method options (Cash on Delivery, bKash / Nagad, Credit Card).
- **📍 Real-Time Live Order Tracking Simulation**:
  - Interactive map preview with moving rider icon.
  - Step-by-step progress timeline: *Order Placed* ➔ *Kitchen Cooking* ➔ *Driver En Route* ➔ *Delivered*.
  - Live countdown timer and driver direct contact button.
- **📍 Dynamic Delivery Location Picker**: HSTU Campus & Halls, Medical Mor Area, Dinajpur Sadar Citywide.
- **💾 LocalStorage State Persistence**: Automatically preserves your cart items, favorite dishes, and theme mode.

---

## 🛠️ Technology Stack

- **Structure**: Semantic HTML5 with accessibility attributes and OpenGraph metadata.
- **Styling**: Vanilla CSS3 design system with custom properties, CSS Grid, Flexbox, glassmorphism filters, and CSS keyframe animations.
- **Typography**: Google Fonts (*Plus Jakarta Sans* & *Outfit*).
- **Icons**: FontAwesome 6 Pro icons.
- **Logic**: Modular Vanilla JavaScript (ES6+) with state management and LocalStorage API.

---

## 🚀 How to Run Locally

1. Open `index.html` directly in any modern web browser, or:
2. Serve via a local dev server (e.g. VS Code Live Server or `python -m http.server 8000` / `npx serve .`).
3. Enjoy the ordering experience!
